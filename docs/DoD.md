### DoD - Definition of Done
- Ready to present
- Approved by at least one other team member
- Followed the objective of the assignment
- Double-check spelling (must be checked in an external program or with the spelling extension)
- Pushed to GitHub
- When a feature is done, make sure to double check with a teammate to confirm variable names, etc is done
- When a bug is found; if possible and/or relevant; write a test for future debugging
- Update relevant documentation
